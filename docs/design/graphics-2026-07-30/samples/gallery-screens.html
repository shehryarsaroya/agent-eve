THE COMPACT · the screen series

Twelve screens, one product. Each maps a window an EVE player already knows onto one of ours — the star map, the Overview, the character sheet, standings, the market, contracts, the corporation window, the fleet window, the probe scanner — plus two that EVE has no equivalent for, which is the point: AUTHORITY and THE RECKONING. Every string is real data out of VISUAL-ASSET-BIBLE.md. All twelve were generated against profile-e-evenative.png as a style reference so the series holds one identity.

EVE’s look, our words. §3’s vocabulary is a rules surface in this project and one word wearing two concepts is its oldest scar, so every prompt in this series carries an explicit ban list — ISK, Fortizar, Rorqual, entosis, ADM, nullsec, corporation, killboard and eighty more — and supplies the canon instead. The scoreboard of this game is promises kept and broken; a kill list would be the wrong drama entirely.

Click any image for full size. Regenerate one cell with python3 render_screens.py --only reckoning.
